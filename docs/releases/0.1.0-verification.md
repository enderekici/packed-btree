## Fresh-repository and consumer check

The core coordinate resolved with transitive dependencies from a fresh local
Maven repository using JDK 17 at 2026-10-26 00:20:08 UTC. To repeat the
resolution with a fresh repository and a JDK 17 Maven wrapper:

```bash
export JDK17_HOME=/path/to/jdk-17
export JDK25_HOME=/path/to/jdk-25
export JAVA_HOME="$JDK17_HOME"
export PATH="$JAVA_HOME/bin:$PATH"
export PUBLIC_M2="$(mktemp -d /tmp/packed-btree-central-m2.XXXXXX)"
./mvnw --batch-mode \
  -N -U org.apache.maven.plugins:maven-dependency-plugin:3.8.1:get \
  -Dartifact=io.github.enderekici:packed-btree:0.1.0 \
  -Dtransitive=true \
  -Dmaven.repo.local="$PUBLIC_M2"
```

The fresh repository's `_remote.repositories` records the core POM/JAR and
parent POM as resolved from Central at that time.

[`DocumentationConsumer.java`](../../results/final-integration/DocumentationConsumer.java)
