## Signing key discovery

Before the first Central deployment, publish the signing key's public part to
both [Ubuntu's OpenPGP keyserver](https://keyserver.ubuntu.com/) and
[keys.openpgp.org](https://keys.openpgp.org/about/api/). Confirm that a lookup
by the full fingerprint returns the expected key before deploying. The
keys.openpgp.org API supports fingerprint-based retrieval; email-based lookup
requires the address owner to verify and opt in. Keyserver availability and
discovery must be checked directly; this record makes no propagation-time
assumption.
